## Evidence-led case studies

Create a case study only after collecting:

1. written permission covering the customer name, logo, quotes, photography, and measured results;
2. the application and operational problem in the customer's own terms;
3. the selected product/model and why it fit the torque range, process, and evidence requirement;
4. baseline and outcome data with units, dates, sample size, and measurement method;
5. CSE's actual role: supply, selection support, setup, verification, calibration, repair, or training;
6. a named internal reviewer who can substantiate every claim; and
7. an expiry/review date for claims that may change.

Recommended page structure: problem, constraints, selection rationale, implementation, verified result, limitations, products used, and a relevant RFQ CTA. If the customer cannot be named, use a truthful anonymous description and omit the logo and quote.

## Campaign URL convention

For links CSE controls, use lowercase values and a short campaign name:

`?utm_source=partner-name&utm_medium=referral&utm_campaign=tohnichi-indonesia`

The website stores only allowlisted UTM fields, the first landing path, a query-free referrer URL, and a coarse channel with an inquiry. It does not store arbitrary landing-page query parameters in inquiry attribution.
